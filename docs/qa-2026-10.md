```bash
cd ~/c-fill
node scripts/qa/_token.mjs                 # segarkan access token Google
bash scripts/qa/run-all.sh                 # semua pemeriksaan
```

(dibuat oleh `_token.mjs`). Token berlaku 1 jam; kalau muncul `401`, jalankan
`_token.mjs` lagi.

"HFSPS" mencari tab `HFSPS (1Y)`, tetapi file itu isinya `HFSPS (1M, 3M)` dan
